🎯 Что такое VideoHub Player?

VideoHub Player — это универсальный видеоплеер, который позволяет воспроизводить видео из различных источников: VK Видео, YouTube, и прямые ссылки на MP4 файлы.

📋 Поддерживаемые форматы

  • VK Видео - видео из ВКонтакте (vk.com/video)
  • YouTube - видео с YouTube (youtube.com, youtu.be)
  • MP4 - прямые ссылки на видео файлы (.mp4)

🚀 Как использовать плеер

  1. Откройте плеер - перейдите на страницу player.html
  2. Вставьте ссылку - скопируйте ссылку на видео и вставьте в поле ввода
  3. Нажмите "Загрузить" - плеер автоматически определит тип видео
  4. Смотрите - наслаждайтесь просмотром!

📤 Как поделиться видео

После загрузки видео вы можете:

  • Скопировать ссылку - нажмите кнопку "Копировать ссылку"
  • Поделиться в соцсетях - используйте кнопки VK, Telegram, WhatsApp
  • Отправить ссылку с хэшем - ссылка будет иметь формат:
    https://yoursite.com/player.html#video-youtube-dQw4w9WgXcQ
💡 Совет: Ссылки с хэшем позволяют открывать видео напрямую. Когда кто-то перейдет по такой ссылке, видео загрузится автоматически!

⚙️ Особенности работы

  • Автоматическое определение - плеер сам распознает тип видео по ссылке
  • Адаптивный дизайн - работает на ПК, планшетах и смартфонах
  • Без регистрации - не требуется создавать аккаунт
  • Бесплатно - полностью бесплатный сервис

❓ Проблемы и решения

Видео не загружается

  • Проверьте правильность ссылки
  • Убедитесь, что видео доступно публично
  • Для VK: видео должно быть с настройками приватности "Все могут смотреть"

Ошибка "Файл не найден"

  • Для VK видео убедитесь, что ссылка содержит owner_id и video_id
  • Проверьте, не удалено ли видео
  • Попробуйте обновить страницу
