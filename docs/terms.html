Условия использования

Последнее обновление: 2024

1. Общие положения

Добро пожаловать на VideoHub Player! Используя наш сервис, вы соглашаетесь с данными условиями использования. Пожалуйста, внимательно прочитайте их перед началом использования.

2. Описание сервиса

VideoHub Player — это веб-приложение, которое позволяет пользователям воспроизводить видео из различных источников, включая:

  • VK Видео (ВКонтакте)
  • YouTube
  • Прямые ссылки на MP4 файлы

3. Правила использования

При использовании нашего сервиса вы обязуетесь:

  • Использовать сервис только в законных целях
  • Не нарушать авторские права третьих лиц
  • Не пытаться обходить технические ограничения платформ
  • Не использовать сервис для распространения незаконного контента
  • Соблюдать условия использования сторонних платформ (VK, YouTube и др.)
⚠️ Важно: Наш сервис не хранит видеофайлы на своих серверах. Все видео воспроизводятся напрямую с оригинальных платформ через официальные API и iframe.

4. Авторские права

Мы уважаем права интеллектуальной собственности. При использовании сервиса:

  • Вы несете полную ответственность за контент, который просматриваете
  • Все права на видео принадлежат их авторам и правообладателям
  • Сервис предназначен только для личного некоммерческого использования
  • Запрещено использование сервиса для пиратского распространения контента

5. Ограничения ответственности

VideoHub Player предоставляется "как есть". Мы не гарантируем:

  • Бесперебойную работу сервиса
  • Доступность всех видео (зависит от сторонних платформ)
  • Отсутствие ошибок в работе приложения
  • Совместимость со всеми браузерами и устройствами

6. Сторонние сервисы

Наш сервис использует следующие сторонние платформы:

  • VK (ВКонтакте) - регулируется условиями использования VK

Используя эти сервисы через наше приложение, вы также соглашаетесь с их условиями.
